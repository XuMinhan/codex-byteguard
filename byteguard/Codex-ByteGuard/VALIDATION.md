## 本地 HTTP/SSE 端到端测试

测试上限 300000 字节，普通请求阈值 270000。使用临时 CODEX_HOME 和本机模拟服务，不加载用户认证、不上传已有聊天。模拟 token 用量固定为 1，排除 token 阈值触发。

| 场景 | 到达模拟服务的请求字节数 | 结果 |
| --- | --- | --- |
| 超限后压缩并续跑 | 普通 41070 → 压缩 262739 → 普通 41656 | 退出 0，返回 BYTE_GUARD_CONTINUED |
| 压缩后仍超限 | 普通 41070 → 压缩 262739 | 退出 1，未发送超限请求 |
| 压缩请求自身超限 | 普通 41070 | 退出 1，压缩请求被本地拦住 |
| 关闭保护 | 普通 41070 → 普通 280455 | 退出 0，没有压缩，恢复上游行为 |

四项断言全部通过。另以桌面内置原版做过对照，普通请求为 40923 → 280455 字节，没有压缩。
