# Codex Chat Guardian — 本地聊天容量预警

适用于 Windows Codex 桌面版。版本 1.0.0，2026-10-15。
这是独立本地 HTML 监控工具，需要 Python 3.10+，仅使用标准库，无需 pip、Node.js 或联网安装依赖。

## 快速开始

1. 将 ZIP 完整解压到固定文件夹，不要直接在压缩包中运行。
2. 双击 `启动监控.cmd`，自动检测 Codex 内置 Python 或系统 Python 3.10+。
3. 浏览器自动打开 http://127.0.0.1:8769/ 。也可以在 Codex 内置浏览器打开此地址。
4. 没有 Python 时，安装 Python 3.10+ 并勾选 Add Python to PATH，然后重新启动工具。
5. 双击 `停止监控.cmd` 可停止本目录启动的服务。关闭页面不会停止后台服务。

CMD 启动器仅对这次 PowerShell 进程使用 ExecutionPolicy Bypass，不修改系统执行策略；公司策略若阻止脚本，请遵循公司规定，使用下方 Python 命令。

## 功能

- 每 15 秒刷新当前用户本机聊天统计，缓存未变化的日志。
- 显示累计内容字节数、压缩后内容估算、最后成功请求的输入 token、历史网关 403、更新时间。
- 搜索、排序、风险筛选、打开对应 Codex 聊天。
- 默认隐藏归档聊天，可勾选显示；过滤 Guardian review 内部审核会话。
- 默认 700 KB 预警、850 KB 高风险；阈值及筛选偏好保存在当前浏览器中。1 KB = 1000 字节。
- 页面打开时显示预警；点击启用系统通知并授权后可推送系统通知。页面关闭后没有通知。

## 数据与隐私

默认读取环境变量 CODEX_HOME 指向的目录；未设置时读取当前用户的 `.codex`。扫描 sessions、archived_sessions，以只读方式查询 state_5.sqlite，并读取 session_index.jsonl 获取标题。

只监听 127.0.0.1，不上传数据，无外部网页依赖。API 返回标题、聊天 ID 与统计信息，不返回聊天正文。聊天标题也可能包含敏感内容，请勿直接分享真实页面截图或 API 输出。

本发布包不含任何聊天日志、数据库、备份、账号配置或个人路径。工具不会撤回对话、修改历史、修改代理配置或安装开机启动项。

## 如何理解预警

字节数是本地 response_item.payload 数组的 UTF-8 紧凑 JSON 长度，不是完整 HTTP 请求体。工具定义、系统指令、请求封装和传输压缩等会使真实请求大小不同。继承的上下文或尚未落盘的内容可能无法完整统计。

压缩后估算采用最近一次 compacted.replacement_history 加后续内容；日志未保存替代历史时显示未知。累计值不会因压缩自动清零。历史 403 标记也不代表当前仍被拦截。

700/850 KB 是经验提醒值，不是已确认的公司网关限制。已有本机样本支持“撤回失败轮次后手动压缩可恢复继续运行”的验证结果，但不能据此保证其他网关或聊天一定有效。403 也可能由其他规则引起。

## 手动运行与排错

在项目目录打开终端：

```powershell
python server.py
```

然后打开 http://127.0.0.1:8769/ ，按 Ctrl+C 停止。也可使用 `py -3 server.py`。

端口冲突时：

```powershell
python server.py --port 8770
```

然后手动打开 http://127.0.0.1:8770/ 。双击启动器固定使用 8769。已存在有效监控服务时会复用；如需切换扫描目录，先停止旧服务。

指定其他本地 Codex 数据目录：

```powershell
python server.py --codex-home "D:\CodexData"
```

列表为空时，检查当前 Windows 用户是否有 Codex 本地聊天，以及 CODEX_HOME 是否正确。数据库暂不可读时查看页面扫描警告。不同 Codex 版本的数据结构可能变化，当前主要适配 state_5.sqlite 与 JSONL 日志格式。

## 项目结构

- server.py：Python 只读扫描与本地 HTTP 服务。
- index.html：无构建步骤、无外部依赖的仪表盘。
- 启动监控.cmd / 启动监控.ps1：Windows 启动入口与运行时检测。
- 停止监控.cmd / 停止监控.ps1：校验进程归属后停止服务。
- README.md：本说明。

分享时发送原始 ZIP；不要将后续生成的 server.pid、聊天备份或本机日志加入发布包。


## v1.1：90% 手动介入提醒

每 5 秒扫描，默认参考容量 1000 KB，900 KB 起在页面常驻列出聊天，并每 60 秒重复提醒（需打开页面并开启提醒；后台浏览器可能降低刷新频率）。参考容量可调整，百分比不是实际请求大小或服务端限制。已归档聊天不进入介入列表。

点击聊天链接，在 Codex 停止当前任务，等待停止，再发送 `/compact`。页面提供复制命令按钮，并通过新增压缩记录提示进展；必须在 Codex 确认完成。日志执行状态可能因崩溃、事件缺失而过时。不会自动续跑。

官方 app-server 有 `turn/interrupt` 和 `thread/compact/start`，但当前桌面实例未暴露可连接的控制 socket，不能从此服务可靠接管任务。因此此版没有自动中断或自动压缩功能，也不强杀进程或修改正在写入的聊天记录。压缩请求本身仍可能遭网关拦截，一次大工具输出也可能跨过阈值。

接口参考：https://developers.openai.com/codex/app-server/


## ByteGuard 项目检测（v1.2）

页面新增 ByteGuard 请求实测面板、来源筛选与每个会话的实测列。新版本的 ByteGuard 启动脚本在 CODEX_HOME/byteguard/status 写入统计，监控读取相同目录。第一次模型请求后会出现记录；旧程序需重新启动，旧记录不能补算实测。

默认检查同级 Codex-ByteGuard 项目目录。项目放在其他位置，可运行 `python server.py --byteguard-project "你的ByteGuard目录"`。即使找不到程序目录，仍会读取已有的实测状态。

状态只含字节数、阈值、线程/进程 ID 和计数；不保存请求正文或认证。进程存活仅表示进程存在，最近检查时间不代表任务当前正在执行。压缩检查次数不等于压缩成功次数。已归档会话默认也从实测列表隐藏。
